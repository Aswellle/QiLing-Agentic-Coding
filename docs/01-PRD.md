## 1. 产品愿景与定位

### 1.1 一句话定位

**启灵是面向中国开发者生态的开源终端编程代理工具——具备 Claude Code 的全部能力，同时深度适配国产 AI 服务和中文开发环境。**

### 1.2 问题陈述

当前编程代理市场的核心痛点：

| 痛点 | 现有工具 | QiLing 解法 |
|---|---|---|
| 锁定境外 AI 服务 | Claude Code、Codex CLI、Cursor | 原生支持 MiniMax、Qwen、Doubao、GLM 等国产模型 |
| 英文优先体验 | 所有主流工具 | 中文界面、中文记忆文件、中文错误提示 |
| 无法私有部署 | Cursor (闭源)、Amp | 完全开源，支持本地 Ollama |
| 工具能力参差 | Aider (无权限)、Cline (VSCode 绑定) | 完整工具系统 + 独立 CLI TUI |
| 高昂使用成本 | Cursor ($20/月)、Amp | 开源免费，用户自带 API Key |

### 1.3 目标用户

**主力用户（P0）：** 中国后端/全栈工程师，日常工作使用 VS Code 或命令行，已有国产 AI 服务账号。

**扩展用户（P1）：** 使用 Anthropic/OpenAI API 的国际开发者，对终端 AI 代理有需求。

**研究用户（P2）：** 基于 QiLing SDK 构建定制代理工具的开发者。

### 2.2 核心功能需求（v0.2 目标）

#### FR-01: 可靠的对话循环
- **FR-01.1** 网络错误（429、529、503）自动重试，指数退避，最大 5 分钟
- **FR-01.2** 流式响应中断后自动恢复（断点续传语义）
- **FR-01.3** 请求超时可配置（默认 120s），超时后展示已收到的内容
- **FR-01.4** 模型输出截断（max_tokens 命中）时提示用户并可继续

#### FR-02: 上下文管理
- **FR-02.1** 实时 token 计数，精确到每次工具调用
- **FR-02.2** 上下文使用率展示（已用 / 总量 / 百分比）
- **FR-02.3** 75% 时黄色预警，90% 时自动触发压缩
- **FR-02.4** 手动 `/compact [指令]` 支持自定义压缩焦点
- **FR-02.5** 压缩后保留工具调用历史的摘要，不丢失重要操作记录
- **FR-02.6** 支持 `/compact --keep-last N` 保留最近 N 轮完整对话

#### FR-03: 工具系统完整性
- **FR-03.1** FileRead 支持分段读取（offset + limit），图片返回 base64
- **FR-03.2** FileEdit 保证 old_string 唯一性检查 + replace_all 模式
- **FR-03.3** FileWrite 自动创建父目录，覆盖前展示 diff 预览
- **FR-03.4** Glob 自动忽略 .gitignore 中的路径
- **FR-03.5** Grep 优先使用 ripgrep，降级到内置实现
- **FR-03.6** Bash/PowerShell 危险命令检测：`rm -rf`、`git reset --hard`、`DROP TABLE` 等，展示警告后等待确认
- **FR-03.7** Agent 子代理防无限递归（最大深度 5 层）
- **FR-03.8** WebFetch 支持 302 重定向跟随，超时 30s

#### FR-04: 权限系统
- **FR-04.1** 工具白名单 glob 模式：`Bash(git *)`, `FileEdit(src/*.ts)`
- **FR-04.2** 权限决策四档：允许一次、本次会话、项目永久、全局永久
- **FR-04.3** 权限请求界面清晰显示：工具名、完整参数、风险等级
- **FR-04.4** YOLO 模式（`--yolo`）：跳过所有确认，适合 CI/CD
- **FR-04.5** 只读模式（`--readonly`）：禁止所有写操作

#### FR-05: Provider 多样性
- **FR-05.1** 原生支持：Anthropic、MiniMax、OpenAI、Google Gemini
- **FR-05.2** 国产模型扩展：阿里云通义千问、字节 Doubao、智谱 GLM
- **FR-05.3** 本地模型：Ollama（`ollama://localhost:11434`）
- **FR-05.4** 自定义 OpenAI 兼容端点（`--endpoint`）
- **FR-05.5** 运行时切换模型（`/model`），无需重启

#### FR-06: 斜杠命令系统
| 命令 | 描述 | 优先级 |
|---|---|---|
| `/help` | 帮助信息 | P0 |
| `/commit` | Git 提交（含安全协议）| P0 |
| `/review [PR#]` | 代码审查 | P0 |
| `/init` | 创建/更新记忆文件 | P0 |
| `/memory` | 查看记忆文件 | P0 |
| `/compact` | 压缩上下文 | P0 |
| `/model` | 切换模型 | P0 |
| `/config` | 查看/修改配置 | P0 |
| `/clear` | 清空对话 | P0 |
| `/exit` | 退出 | P0 |
| `/plan` | 进入计划模式（只读探索）| P1 |
| `/pr` | 创建 Pull Request | P1 |
| `/test` | 运行测试并修复 | P1 |
| `/cost` | 显示 token 使用成本 | P1 |
| `/history` | 搜索历史对话 | P2 |
| `/mcp` | 管理 MCP 服务器 | P2 |

#### FR-07: TUI 交互
- **FR-07.1** 启动画面：QiLing ASCII 艺术字 + Provider/Model/Endpoint 信息
- **FR-07.2** 消息气泡区分 user（蓝色）/assistant（绿色）/system（灰色）
- **FR-07.3** 工具调用状态：运行中（spinner）/完成（✓）/失败（✗）
- **FR-07.4** 输入框：斜杠命令补全（/输入过滤）、Tab 补全、历史回溯（↑↓）
- **FR-07.5** 底部状态栏：模型名、token 使用量、流式状态、当前目录
- **FR-07.6** 长对话支持滚动（Ink 原生处理）
- **FR-07.7** 权限弹窗阻塞输入，选择后恢复

#### FR-08: 设置与记忆系统
- **FR-08.1** 配置优先级：CLI 参数 > 项目配置 > 用户全局配置 > 默认值
- **FR-08.2** 记忆文件自动加载：`~/.qiling/QILING.md` + `./QILING.md` + `./CLAUDE.md`
- **FR-08.3** 向上查找记忆文件（同 Claude Code 行为）
- **FR-08.4** `/init` 创建/更新记忆文件，AI 辅助提取项目关键信息

#### FR-09: 分发与安装
- **FR-09.1** 单二进制文件（`bun build --compile`），无需安装 Node/Bun
- **FR-09.2** 全平台支持：Windows x64、macOS arm64/x64、Linux x64/arm64
- **FR-09.3** 安装脚本：`curl -fsSL https://qiling.dev/install | bash`
- **FR-09.4** Windows：winget/scoop 包
- **FR-09.5** 自动更新检查（启动时，可禁用）

## 3. 非功能需求

### 3.1 性能
- 启动时间 < 500ms（不含首次网络请求）
- TUI 渲染帧率 ≥ 30fps
- 内存占用 < 200MB（正常会话）

### 3.2 可靠性
- 对话历史本地持久化，进程崩溃后可恢复
- 网络中断后自动重试，不丢失用户输入
- API 限流时自动退避，不崩溃

### 3.3 安全性
- API Key 只存在于 `~/.qiling/settings.json`（mode 0600），不进入日志/历史
- 破坏性 shell 命令触发确认对话框
- FileWrite 覆盖已有文件前展示 diff 确认

### 3.4 可维护性
- TypeScript 全覆盖，严格模式
- 核心模块单元测试覆盖率 ≥ 80%
- 所有公开 API 有 JSDoc 注释

---

## 4. 排除在外

以下功能明确不在 v1.0 范围内：

- **GUI 桌面应用** — 纯 CLI/TUI
- **云端功能** — 不存储用户数据到 QiLing 服务器
- **代码自动补全** — 不做 inline suggestion（已有 Cursor/Continue）
- **图像生成** — 不集成图片生成 API
- **多人协作实时同步** — 单用户工具
