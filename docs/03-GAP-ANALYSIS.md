# 启灵 (QiLing) — 差距分析报告

> **当前版本**: v0.1.0 | **对标基线**: Claude Code CLI v2.1.88 + 生产可用标准  
> **评估日期**: 2026-05-01

---

## 1. 执行摘要

QiLing v0.1 已实现约 **35%** 的 Claude Code 功能，具备基本可运行的骨架，但距离生产可用还有明显差距。核心瓶颈集中在三个领域：**生产可靠性**（重试/错误恢复）、**上下文管理**（完整 compact 引擎）、**MCP 生态完整性**。

```
功能完成度评估（v0.1 现状）

  工具系统       ████████░░  80%  ✅ 基本完整
  TUI 组件       ██████░░░░  60%  ⚠️  缺滚动/键位/成本显示
  权限系统       ██████░░░░  60%  ⚠️  规则引擎有，UI 体验弱
  Provider 接入  ██████░░░░  55%  ⚠️  接口有，国产模型不全
  命令系统       █████░░░░░  50%  ⚠️  主要命令有，缺健壮性
  上下文管理     ███░░░░░░░  30%  ❌  仅基础 compact，无压缩引擎
  错误恢复       ██░░░░░░░░  20%  ❌  无重试，无断点恢复
  MCP 支持       ██░░░░░░░░  20%  ❌  仅 stdio 连接，无生命周期
  测试覆盖       ░░░░░░░░░░   0%  ❌  无任何测试
  分发打包       ██░░░░░░░░  20%  ❌  可本地运行，无发布流程
  文档           ████░░░░░░  40%  ⚠️  文档开始补全中
```

## 3. 生产可用差距总结

### 3.1 阻断发布的问题（P0 Blocker）

| # | 问题 | 影响 | 工作量 |
|---|---|---|---|
| B-1 | 无 API 重试机制：429/529 直接失败 | 高流量场景频繁崩溃 | 3天 |
| B-2 | Compact 丢失工具调用记录 | 长任务后无法追溯操作历史 | 3天 |
| B-3 | Ctrl+C 无法中断流式输出 | 用户无法取消长请求 | 2天 |
| B-4 | 无测试覆盖 | 无法验证基础功能正确性 | 5天 |

### 3.2 严重影响体验的问题（P1）

| # | 问题 | 影响 | 工作量 |
|---|---|---|---|
| P1-1 | Bash 安全检查不完整（仅 5 种模式）| 危险命令未拦截 | 2天 |
| P1-2 | FileEdit 无 diff 可视化 | 用户看不到具体改了什么 | 1天 |
| P1-3 | 无成本追踪（每次请求花费不可见）| 用户难以控制成本 | 1天 |
| P1-4 | Glob 不读取 .gitignore | 返回应忽略的文件 | 1天 |
| P1-5 | 国产模型缺失（Qwen/Doubao/GLM）| 主力目标用户无法使用 | 3天/模型 |
| P1-6 | /plan 命令缺失 | 无安全的只读探索模式 | 3天 |

### 3.3 完善性问题（P2）

## 4. 距离可投入生产的估算

| 阶段 | 目标 | 工作量估算 |
|---|---|---|
| **v0.2 Production Baseline** | 解决所有 P0 Blocker，P1 问题大部分 | **3-4 周** |
| **v0.3 Feature Complete** | 完整 MCP，Plan/Act，国产模型全覆盖 | **6-8 周** |
| **v1.0 GA** | 分发渠道，自动更新，稳定 API，完整文档 | **12-16 周** |

**结论**: QiLing 距离可投入生产（v0.2）还需约 **3-4 周**集中开发，解决可靠性问题是首要任务。
